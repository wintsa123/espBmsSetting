# AE5 首页默认车图

`ae5.webp` 直接复制自原 dashboard 配套静态产物仓库 `lswlc33/zeeho-3d-models` 的 `art/` 目录中公开的 AE5 专属立绘，未生成、裁剪或重新编码。画面为绿色贴花 AE5 实车，原车身的 AE5 标识保留。

- 来源仓库：`https://github.com/lswlc33/zeeho-3d-models`
- 来源 checkout 提交：`174420cb32c80e1c1eb5917cbfcbf9a643059c8b`
- 原素材最近修改提交：`a79278850ab83cdf0ecf0f135545bab67cff5e6d`
- 素材目录：`art/`，该提交下唯一的 WebP 文件；原文件名含公开车辆标识，本项目改用不关联车辆的通用文件名。
- 文件尺寸：900 × 686 像素，WebP RGBA，透明背景。
- 文件大小：96158 字节。
- SHA-256：`b75d902670cdc5d46a63cc232f7b9b4928428bf9df7868bf9d31e5690fd2f0e7`。

原 dashboard `public/js/app.js` 的 `artBase` / `viewHome` 优先使用这类专属立绘，找不到时回退至接口车辆图片。此图是原项目已有的具体 AE5 车辆外观，不表示所有 AE5 都使用相同贴花。

来源代码及图像按用户指定复用；本记录不构成额外授权，也未将第三方组件许可套用于车图。用户可在车辆卡片上传自己的车辆图片替换默认展示。
